# Reply Hider for the 24th Letter

X (旧 Twitter) で、**指定したユーザーが書いたリプライだけ**を非表示にする Chrome 拡張 (MV3)。

フォローはしているものの、その人が他人とする会話には興味がない。そんな温度感のための拡張です。  
ミュートやブロックと違って、そのユーザー本人のポストや連投スレッドはそのまま見えます。  
他人の会話に入っていくリプライだけが消えます。

## できること

- **リプライだけを隠す**: 登録した @handle のユーザーが他人に書いたリプライを、会話・リプライ欄・タイムラインから隠します。
  - 本人への返信 (連投スレッド) は残します。
  - 開いているポストそのものは、登録ユーザーのリプライでも残します。
- **ユーザーごとのオン/オフ**: 登録を消さずに、トグルで一時的に非表示を止められます。
- **表示名の自動取得**: x.com 上で見かけた登録ユーザーの表示名を覚え、ポップアップの一覧に @handle と並べて出します。相手が改名していれば、次に見かけたときに更新します。
- **自分宛てのリプライを表示するオプション**: オンにすると、登録ユーザーのリプライでも自分 (ログイン中のアカウント) 宛てのものは隠しません。返信したいときに見落とさずに済みます。
- **縦線を残すオプション**: 隠したリプライを丸ごと消す代わりに1行分に縮め、会話の縦線だけ残します。「ここに隠したリプライがある」とわかります。

## インストール

1. このリポジトリをクローンするか ZIP でダウンロードして展開する
2. `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

## 使い方

1. ツールバーのアイコンをクリックしてポップアップを開く
2. 入力欄に隠したいユーザーの @handle を入れて＋ボタン (または Enter)
3. x.com を開くと、そのユーザーのリプライが表示されなくなる

登録は `chrome.storage.sync` に保存されるので、同じ Google アカウントの Chrome 間で同期されます。

## プライバシー

登録内容と設定はブラウザ内 (`chrome.storage`) にだけ保存し、外部には送信しません。詳しくは [プライバシーポリシー](PRIVACY.md) をご覧ください。
