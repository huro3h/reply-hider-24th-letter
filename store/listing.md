# Chrome Web Store 申請用の下書き

デベロッパー ダッシュボードの各欄に貼る文面をまとめたもの。

## ストアの掲載情報

### 名前（manifest の `name` から自動で入る）

Reply Hider for the 24th Letter

### 概要（manifest の `description` から自動で入る。132 文字以内）

x.com で、指定したユーザーが他人に書いたリプライだけを非表示にします。本人のポストや連投スレッドはそのまま見えます。

### 説明

```
フォローはしているものの、その人が他人とする会話には興味がない。そんなときのための拡張機能です。

x.com で、指定したユーザーが他人に書いたリプライだけを非表示にします。
ミュートやブロックと違い、そのユーザー本人のポストや連投スレッドはそのまま表示されます。

■ 主な機能
・リプライだけを隠す
  登録したユーザーが他人に書いたリプライを、タイムライン・会話・リプライ欄から隠します。
  本人への返信（連投スレッド）と、開いているポストそのものは残します。
・自分宛てのリプライは表示
  オンにすると、登録したユーザーのリプライでも、自分宛てのものは隠しません。
・ユーザーごとのオン/オフ
  登録を消さずに、一時的に非表示を止められます。
・会話の流れを保つ
  隠したリプライの後にも会話が続くときは、縦線を点線でつなぎ、間を省略したことを示します。
・縦線を残すオプション
  隠したリプライを1行分に縮め、「ここに隠したリプライがある」とわかるようにします。
・表示名の自動取得
  x.com で見かけた登録ユーザーの表示名を覚え、一覧に @handle と並べて表示します。

■ 使い方
1. ツールバーのアイコンをクリックしてポップアップを開く
2. 隠したいユーザーの @handle を入力して追加する
3. x.com を開くと、そのユーザーが他人に書いたリプライが表示されなくなります

■ プライバシー
登録内容と設定はブラウザ内（chrome.storage）にだけ保存し、外部には送信しません。
詳しくはプライバシーポリシーをご覧ください。

■ 注意
・X Corp. とは関係のない、個人が作った非公式のツールです。
・x.com の画面の作りが変わると、正しく動かなくなることがあります。

ソースコード: https://github.com/huro3h/reply-hider-24th-letter
```

## プライバシーへの取り組み

### 単一用途の説明

```
x.com で、ユーザーが指定したアカウントが他人に書いたリプライを非表示にします。
```

### 権限が必要な理由

**storage**

```
登録したユーザーの一覧、オプションの設定、ポップアップに表示する登録ユーザーの表示名を保存するために使います。
```

**ホスト権限（コンテンツ スクリプトの対象: x.com / twitter.com）**

```
x.com のページ上で、表示されている各ポストが登録したユーザーのリプライかどうかを判定し、非表示にするために使います。対象は x.com と twitter.com だけです。
```

**リモートコード**

「いいえ、リモートコードを使用していません」を選ぶ。JS はすべてパッケージに含めている。

### データの使用

- 収集するデータの種類: どれにもチェックを付けない（外部に送信していないため）
- 3つの宣誓（データを販売しない、単一用途と無関係な目的に使わない、信用力の判断に使わない）: すべてチェックを付ける
